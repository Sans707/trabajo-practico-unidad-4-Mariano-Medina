# Glosario de TypeScript

PATH - Es la direccion que le indica a la computadora dónde buscar los archivos.

dist - Es la carpeta donde se guarda el código final después de que la computadora lo procesa.

class - Es como un molde para fabricar objetos que comparten las mismas caracteriticas.

npm - Node Package Manager, es una biblioteca de codigo abierto.

npx - Es como un botón para ejecutar herramientas de esa biblioteca, sin tener que instalarlas permanentemente.

strict - Se usa para que revise el código que no deje pasar ningun minimo error.

extends (interface) - Sirve para heredar, a una estructura base le podemos sumar nuevas propiedad sin tener que escribir todo denuevo.

Tipo literal - Es cuando una variable no acepta cualquier valor, solo uno exacto.

include - Es la lista de instrucciones que le dice a TypeScript que archivos traducir.

node - Programa que permite a la computadora entender y ejecutar código de programación fuera del navegador.
